# 黄山派圆角屏加大字体版

2026-09-20，继续处理字体偏小、手动点击费力和圆角处不应放文字的反馈。

## 布局

应用设计宽度 480，板端宽度 390，以下为换算后的实际像素约值。

| 内容 | 本版 |
| --- | --- |
| 首页运动名称 | 41 px |
| 页面标题、开始／停止文字 | 33 px |
| 常用说明、列表文字 | 24–26 px |
| 开始／停止按钮 | 312×62 px |
| 上一页／下一页按钮 | 117×59 px |

标题居中，去掉首页右上角标签，将“演示”合并到标题。翻页按钮向内收拢，四个角各保留约 80×65 px 的无文字区域。首页减少重复说明，完整保留心率、步数、强度标签与开始／停止入口。

时间线、历史、设备诊断和复盘文字使用大字列表；内容超出可视区域时可向上滑动。复盘文字拆成短行，避免固定大文本框垂直居中使首行不可见。训练时其他页面的停止按钮占据独立操作位置，隐藏该位置的其他动作，避免覆盖。

列表参考小米官方 [list](https://iot.mi.com/vela/quickapp/zh/components/container/list.html) 和 [list-item](https://iot.mi.com/vela/quickapp/zh/components/container/list-item.html) 文档，明确指定列表高度、项目类型和尺寸。

截图由实板 LVGL 渲染数据经串口读回并校验压缩数据，不是模拟器截图或物理屏幕照片。合成点击、滑动仅验证应用事件链路，不等同于手指触摸验收。自动操作需结合后续截图确认，不能仅凭探针收到命令判定应用响应。

`audit-corners.py` 统计四角区域中亮度低于 150 的像素，辅助确认没有文字笔画；它不测量实体屏幕的圆角半径。演示数据、真实传感器 JS 接入和断电后 RAM 历史丢失等能力边界仍见部署 README。

`corner-safe-*` 是布局检查过程中的截图；最终固件证据使用 `corner-final-*`。
