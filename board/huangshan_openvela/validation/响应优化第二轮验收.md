# 黄山派响应优化第二轮验收

2026-09-22。已烧录并校验。延迟明显下降，但**尚未达到市售手表的流畅目标**；首页停止训练、冷启动和首次建页仍然偏慢。

## 本轮实测

对比上一轮交付的 PARTIAL 固件，而非更早的整屏重绘版本。新固件重启后测了两轮，另测原生桌面 18 次。统计见 `responsive-comparison.json`，原始结果与串口日志以 `responsive-final`、`responsive-repeat`、`responsive-native` 命名。

缓存切页下降约 33%，训练中切页下降约 37%，开始训练下降约 50%。本版首次进入三个其他页面仍为 740–1139 ms。原生桌面 18 次中位数 241 ms，首次访问最大 364 ms；后两轮复用页面 12 次为 211–244 ms，中位数 238.5 ms。

这些是设备端合成 LVGL 按下至页面标志变化后的刷新完成时间，包含约 100 ms 的按压及调度延误，不含物理触摸采样和面板像素响应。不是手指到光的测量，也不是最坏时延保证。停止训练仍同步执行摘要、保存和界面更新，没有用提前显示“完成”来掩盖后台收尾。

## 已实施的修正

1. **Flash 指令读取从单线改为双线。** 原来 XIP 保留启动阶段的 `0x0B` 单线读取（HCMDR/HRCCR），现在在界面初始化前切为 `0x3B` 双线数据读取，时钟保持原值。切换函数及常量位于 SRAM，期间屏蔽中断；启动时比较覆盖整片地址空间的 512 个 32 字节位置，不一致自动恢复原模式。没有擦写 Flash 状态寄存器，没有提高 CPU 或 Flash 时钟。保留上一轮局部刷新模式。
2. **避免无用的响应式更新。** 切页时只修改变化的页面状态字段，保留对象身份；训练时只生成当前页的概率/时间线列表，进入页面及重新显示时从最新结果补齐。风险判断、趋势原始采样和识别仍持续运行。未显示的趋势图、风险列表及活动占比不再每个批次重新格式化；保存时仍生成完整摘要和趋势。
3. **复用启停相关控件。** 停止按钮、二级操作和页码点改为切换可见性，减少开始/停止时跨隐藏页面销毁和重建控件。删除停止流程中重复调用的导出预览；重复文本的分行结果继续复用。
4. **桌面动作调度间隔从 100 ms 改为 20 ms。** 应用退出请求先记录标志，再由 GUI 线程处理；实际 QuickApp JS 模式保持同步。

## Flash 校验与排除项

CPU 抽样热点分散于 QuickJS 执行、分配/释放、布局和软件绘制，没有证据表明字形生成是唯一或主要瓶颈。寄存器检查确认缓存已开启；原生编译已有 `-Os` 优化，并非调试版未优化。

尝试过运行时异步 JS 模式，但训练切页达到约 1.9–3.0 秒，已经撤回，未进入交付版本。记录：`../logs/async-only.log`、`cpu-hotspots-cpu.json`。

四线读取抽样未通过，已恢复，未启用。最初每 4 KiB 来回切换协议的逐字比较，在 `0x12001000` 出现差异；降低时钟仍复现，而单独单线/双线读取该地址均与原始备份一致。不能据此把原因直接定为时钟过高；这种反复切换诊断已被弃用。

最终采用连续两遍全片读取、中间只切换一次协议，按 64 KiB 块计算 CRC32，并显式同步缓存与内存访问。全部 16,777,216 字节、256 块 CRC 一致。中间校验镜像和最终交付镜像各通过一次，最终证据在 `../logs/responsive-final.log`：`VMC_XIP full_bytes=16777216 ok=1`。两轮重启均为 `VMC_XIP boot dual=1`。这验证本机当前运行条件，不代表温度/电压范围的长期硬件资格认证。

校验函数反汇编见 `xip-ram-disassembly.txt`，没有跳到 Flash 的函数调用。日常启动只进行轻量抽样；全片 CRC 是手工诊断命令，期间会暂停界面，不能在用户交互或计时验收期间调用。

## 功能与画面

- 54 项核心测试、7 项手势测试、界面更新/分片计算测试及运动识别冒烟测试通过。新增用生产页面方法执行的测试，验证隐藏页不生成列表，切页立即采用最新识别结果，并保持页面状态对象身份。
- 两轮训练导航、后台训练、桌面恢复和停止通过；其中第二轮从初筛页点击全局停止。存储日志记录摘要、片段、活动占比和趋势写入。存储仍不保证跨重启保留，真实六轴/手机互联能力未由本轮补齐。
- 板端六张 `responsive-*.png` 验证左右手势、返回桌面。六张的四角 80×65 像素区域均通过留白审计。工具页、待机首页与原先大字版本静态像素差为 **0**；左滑后右滑回初筛的画面差为 **0**。详见 `responsive-corner-audit.json` 和 `responsive-pixel-comparison.json`。
- 截图来自 LVGL 快照，不是物理面板照片。没有重新要求用户确认实体触摸和显示，因此清单中的本版用户确认标志仍为 false。
- 最后已停止训练、关闭性能输出、校时并返回桌面，串口释放。空闲堆 5,463,680 B；本轮未见内存耗尽或崩溃。原有桌面全部工具的详细行为沿用上一轮验收，本轮重新覆盖工具、秒表、设置、返回和桌面恢复。
