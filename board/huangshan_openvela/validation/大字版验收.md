# 黄山派大字版 UI

2026-09-20，针对用户反馈的字体过小、操作吃力，调整 390×450 屏幕上的 VelaMotion Coach。

## 改动

| 内容 | 旧版实际像素（约） | 大字版实际像素（约） |
| --- | --- | --- |
| 常用辅助文字 | 9–11 | 20–21 |
| 当前运动名称 | 26 | 34 |
| 开始／停止按钮文字 | 18 | 26 |
| 开始／停止按钮高度 | 33 | 52 |
| 翻页按钮尺寸 | 46×28 | 107×49 |

应用采用 480 设计宽度，上表按 390/480 换算。主要阅读文字和操作按钮放大；较次要的设备诊断行仍使用约 16 像素字号，完整保留诊断结果。

- 利用屏幕底部空间放置“上一页／下一页”和训练中的全局停止，保留内容区与操作区之间的间隔。
- 用“心率／步数／强度”“总时长／活动／提醒”等完整标签替换不明确的单字缩写。
- 时间线按纵向排列最近五个运动片段，时长与名称同行；训练中的标记改为字体支持的“中”。
- 场景页专注于六个大按钮，复盘集中到时间线；移除重复的小图表和会截断的摘要。
- 加深浅蓝、浅绿等状态文字的颜色，彩色进度条保留。
- 固定按钮只绑定触摸按下事件，修复训练计算期间点击释放事件不响应的问题，避免同时绑定两种事件导致重复操作。

## 验证

应用打包成功，核心回归测试 54 项通过（`logs/large-type-core-tests.log`），sftool 写入校验通过（`logs/large-release-flash.log`）。启动日志未见 OOM、assert、panic。

最终镜像上的自动操作验证：

- [首页](large-release-home.png)：主要文字、完整指标名、大按钮和底部导航均完整显示。
- [训练中初筛](large-release-coach.png)：开始后能切换页面，“保持自然运动”等短提示完整显示。
- [停止并保存](large-release-stopped.png)：返回首页后用主按钮停止，按钮恢复“开始”；`logs/large-release-stopped-hexdump.log` 确认写入 35 秒模拟训练记录。
- [历史](large-release-history.png)：保存记录可显示，标题、日期和清空按钮均放大。
- [时间线](large-release-timeline.png)：片段纵向排列，名称、时长清楚；[复盘](large-release-review.png) 中总时长、活动时间、提醒和摘要不再重叠。
- [同步](large-release-sync.png)：时长、片段、提醒按纵向排版，检测／发送使用大按钮。

自动验收工具现在等待板端确认每次操作完成再继续，避免训练负载较高时连续命令覆盖；每张截图均校验压缩数据后解码。

再次复位后自动启动正常，空闲堆为 5,525,320 字节，已停留在[大字版首页](large-release-ready.png)待机，串口已释放。启动日志为 `logs/large-release-reboot.log`。

所有截图是实板 GUI 渲染数据经串口取回，不是模拟器截图。合成触摸验证应用操作链路，不能等同于物理手指触摸验收。此前真实六轴 JS 接口、RAM 临时存储等能力边界没有变化，详见部署 README。

`large-type-*` 和 `large-final-*` 是排版迭代过程中的截图；最终验收使用 `large-release-*` 截图。以本记录中的镜像哈希及 `quickapp-firmware-manifest.json` 为准。
