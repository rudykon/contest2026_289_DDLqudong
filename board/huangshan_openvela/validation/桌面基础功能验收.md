# 黄山派桌面基础功能（2026-09-22）

本版本运行在黄山派 SF32LB52 的 openvela/NuttX 上，是项目自定义原生 LVGL 桌面，不是 openvela 官方桌面。保留上一版小芽快应用及其性能优化，增加秒表、倒计时、亮度、手动校时、系统信息和防误触锁屏。

## 固件与实现

- 固件：`../firmware/velamotion-openvela.bin`，9,316,168 字节，地址 `0x12010000`。
- SHA256：`31321faa5119aa73c7401487b71ce3fa076788a7e4ecd12ba2bba31ae0660914`。
- 已使用 COM5、1,000,000 baud 的 sftool `write_flash --verify` 写入并校验，进程成功退出。记录：`../logs/desktop-tools-final-flash.log`。
- 编译日志：WSL `/opt/openvela/logs/desktop-tools-final-build.log`；工具链和构建目录仍在 D 盘 WSL。
- 快应用 RPK 未修改，SHA256 仍为 `851a2884e107d62313c4bb1e2950120521bc7ef7fcbba542ae3485b330d834aa`。
- 回退固件：`../firmware/velamotion-before-desktop-tools.bin`，配套清单 `../manifest-before-desktop-tools.json`。
- 原生页面按需创建，离开时释放页面控件；小芽使用单独屏幕并保留运行实例。时间数字只在变化时重绘，后台工具不重绘。秒表、倒计时使用 `CLOCK_MONOTONIC`，校时不改变它们的计时基准。
- CO5300 硬件亮度经 LCD contrast ioctl 接入；与 LVGL 同线程调用，刷新 PUTAREA 同步等待 DMA 完成。QuickApp 的 `system.brightness` API 本身仍未实现。

## 使用与限制

- 首页“工具”进入秒表、倒计时、系统信息；“设置”进入亮度和北京时间设置。
- 校时页点击中央字段切换年/月/日/时/分，用加减按钮调整，最后保存。当前预编译运行时使用 32 位时间，年份范围限定为 2025–2037。
- 倒计时以分钟调整，最短 10 秒、最长 99 分钟；暂停后调节会设定新的完整时长。“复位”停止并恢复选定时长。
- 到时只有屏幕提醒，没有声音、振动或手机通知。锁屏是防误触，不是密码锁或休眠。
- 亮度为硬件命令设置值，缓存回读不代表光度测量；没有获得本轮物理亮度或触摸反馈。
- `/data` 仍是 RAM，重启后计时状态丢失、亮度恢复 80%，时间需要重新设置。没有增加假电量、心率或手机连接状态。
- 前一版性能数字见 `性能优化验收.md`，对应旧固件；本版保留相关快应用源码和 RPK，未把旧数字当作本版重新测量结果。
